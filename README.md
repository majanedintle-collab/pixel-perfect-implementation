#  AI Workplace Productivity Assistant

## Project Overview

The **AI Workplace Productivity Assistant** is a modern, responsive web application designed to help professionals and students manage their daily workplace tasks more effectively using AI-powered productivity tools.

The application provides three main features: an **AI Task Planner**, **AI Research Assistant**, and **AI Workplace Chatbot**. Users can create daily or weekly schedules, prioritize tasks, summarize research topics, generate insights and recommendations, and interact with an AI-style workplace assistant.

The application was developed as a **frontend-only prototype**, meaning that it does not require a backend, database, authentication system, or external AI API.

---

## Features Implemented

###  AI Task Planner

* Create and organize workplace tasks.
* Add task names, deadlines, priorities, estimated time, and notes.
* Generate daily productivity schedules.
* Generate weekly productivity schedules.
* Prioritize tasks based on urgency and importance.
* Display generated schedules in a structured format.
* Edit generated AI outputs.
* Copy and regenerate generated results.

###  AI Research Assistant

* Enter a research topic or article content.
* Generate structured summaries.
* Display key research insights.
* Provide recommendations based on the entered topic.
* Select the desired output length.
* Edit generated research results.
* Copy or regenerate AI-generated content.

###  AI Workplace Chatbot

* Interactive AI-style chatbot interface.
* Allows users to ask workplace productivity questions.
* Provides simulated AI responses.
* Includes suggested prompts such as:

  * Help me plan my workday.
  * Summarize this topic.
  * How can I improve my productivity?
  * Help me prioritize these tasks.

###  Modern Dashboard

* Modern SaaS-style dashboard.
* Responsive sidebar navigation.
* Productivity summary cards.
* Recent activity section.
* Quick-access feature cards.
* Responsive design for desktop, tablet, and mobile devices.

###  Responsible AI

The application includes a Responsible AI disclaimer informing users that AI-generated information may contain errors and should be reviewed before being used for important professional decisions.

## Setup Instructions

### 1. Clone the Repository

Clone the project from GitHub using:

```bash
git clone https://github.com/your-username/ai-workplace-productivity-assistant.git
```

### 2. Navigate to the Project Folder

```bash
cd ai-workplace-productivity-assistant
```

### 3. Install Dependencies

If the project uses Node.js and React, install the required dependencies:

```bash
npm install
```

### 4. Start the Development Server

Run the application using:

```bash
npm run dev
```

### 5. Open the Application

After starting the development server, open the local URL provided in the terminal. It will normally be similar to:

```text
http://localhost:5173
```
